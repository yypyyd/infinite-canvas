# 画布工作流

## 适用
在画布上搭建可复用的生成流程、批量整理节点，把方案落成节点和连线。

## 节点语义
- 图片、视频、音频节点：素材和产物。
- 文本节点：文案、提示词、分镜等文字内容。
- 配置节点：一个可重复执行的生成入口，记录 mode（image 或 video）、提示词和生成规格；上游连线是参考素材和文本输入，下游连线是产物。
- 连线表示"来源 → 产物"的依赖关系，方向从左到右。

## 布局规则
- 流程从左到右：素材 → 文本或配置 → 产物；同一层级的节点纵向对齐，间距 40–80。
- 新内容放在视口内的空白处，不要压住已有节点；一组相关节点用一次 canvas_apply_ops 摆好（新建节点用 ref 命名，同批里直接连线）。
- 只移动与任务相关的节点；用户没要求时不重排整块画布。

## 什么时候建配置节点
- 用户想反复生成、批量改参数或保留生成入口时，建配置节点，写全 mode、prompt 和规格，sourceNodeIds 连上参考素材；之后生成时传 configNodeId。
- 一次性的生成直接调用生成工具，不要为了形式建空壳配置。

## 批量搭建
1. 用 canvas_plan 列出要建的节点组。
2. 用一次 canvas_apply_ops 完成同一组的文本、配置和连线。
3. 需要生成的再逐个调用生成工具（传 configNodeId），完成后简短说明画布上新增了什么。
