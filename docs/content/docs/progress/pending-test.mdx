# 待测试

本文档只记录已经实现、尚未完成验收的能力。测试按风险分为三个优先级：

- **P0 发布阻断**：涉及数据安全、租户隔离、计费、持久化或核心生成链路；未通过时不建议发布。
- **P1 核心体验**：影响主要业务流程和高频操作；应在当前版本发布前尽量完成。
- **P2 一般回归**：界面细节、文档、品牌一致性和低风险交互；可在 P0、P1 稳定后集中验证。

完成测试后直接删除对应条目；发现问题时回到代码修复，不把未实现功能写入本文档。

## P1 · 核心体验

### 电商工作台与企业中心

- 验证画布“一键电商素材包”：底部工具栏可打开轻量配置抽屉，读取当前企业的商品与 SKU，并可一次选择淘宝、京东、抖音、小红书及商品主图、场景图、详情页图、整套文案和短视频；创建后应按平台纵向编排商品资料与生成配置节点，立即生成时按顺序复用现有图片、文本、视频链路，仅编排时不产生模型请求。选择 1–4 张画布图片时应作为图片和视频参考，未选择时使用所选 SKU 最多 4 张服务端参考图；刷新后节点、连线、提示词和结果可从服务端恢复，切换企业后商品、SKU 和私有参考图不得串租户。验证任一生成项失败不影响已完成结果，配置节点仍可单独调整、重试或停止。
- 验证首页、生图页和画布库的商品主图、场景图、详情页、促销图、服饰模特图和 SKU 系列图入口；模板跳转、提示词自动带入、模板切换和快捷创建画布项目正常。
- 验证企业中心的成员分页搜索、品牌 Logo 与规范、商品/SPU/SKU、最多 50 张 SKU 参考图、批量任务列表及审计日志；关闭上传弹窗或取消新增时，晚到上传结果和旧表单数据不能污染下一次编辑。
- 验证批量生产结果审核：所有者、管理员和审核人可以通过或驳回完成项并填写批注，普通成员不能审核；驳回必须填写批注，失败项或已驳回项可进入新的生产轮次，旧结果解除文件引用；同一任务内每个商品只能选择一个未驳回结果作为主图，旧页面不能审核、重试或选择已经进入新轮次的结果。
- 验证批量结果打包下载：下载包只包含审核通过且文件仍有效的结果，按商品编码建立目录、按 SKU 编码命名并标记主图；跨企业任务、没有通过项、私有存储未配置、源文件缺失或总量超过 2GB 时拒绝下载，临时 ZIP 在响应结束后清理，压缩包内不能出现路径穿越或重复覆盖。
- 验证审核通过的批量结果可以保存到企业素材库或新建画布：同一生产项和轮次重复操作不会产生重复素材或画布，保存失败后再次操作可以继续提交待同步记录；素材和画布只引用原有服务端文件，不重新上传或写入浏览器持久化，普通成员、管理员和所有者可操作，审核人保持只读；切换企业后结果、素材和画布不能串租户。
- 验证企业生产模板与版本管理：所有者和管理员可以创建、启停并发布新版本，普通成员和审核人只能查看；模板名称企业内唯一，旧版本不可覆盖，旧页面保存会被乐观锁拒绝。创建批量任务时可选择内置或企业模板及明确版本，任务固化的提示词不受后续模板更新影响；最终提示词预览与 Worker 使用同一拼装逻辑，正确注入品牌语气、视觉规范、禁用词、商品卖点和所选 SKU 属性，跨企业模板、商品、品牌或 SKU 不能预览或创建任务。
- 验证渠道交付规格：创建任务可选择保留原始结果、淘宝主图、京东主图、抖音商品竖图和小红书商品封面，任务列表显示固化的平台，提示词预览和 Worker 都包含目标渠道与画幅；淘宝、京东结果应为 800×800 JPEG，抖音结果应为 1080×1440 JPEG，小红书结果应为 1242×1660 JPEG，横图与竖图输入均居中裁切且不拉伸。内置与外部执行器应统一校验源文件大小和 MIME 后转换，压缩包扩展名、商品目录、SKU、主图标记和规格命名规则一致；同一请求号改动模板版本或渠道规格必须返回冲突，任务创建后规格列表变化不能改变已提交任务。
- 验证批量结果质量评估与对比：任务项只能选择有结果的完成项，同页可选 2–4 项并排查看生成图、任务创建时固化的品牌规范、禁用词、商品/SKU 名称属性和最多 6 张 SKU 参考图；自动检查应核对商品资料完整性、实际图片尺寸、归档 MIME/大小及生成输入禁用词冲突，品牌或商品后来修改不能改变历史任务核对卡。商品外观一致性、品牌规范命中和图片文字禁用词由审核人逐项勾选，未全部勾选或自动检查存在错误时不能通过，但仍可驳回；所有者、管理员和审核人可从对比页通过、驳回或设为主图，普通成员只读，翻页、搜索、切换任务或企业后旧选片不应残留，跨企业文件与快照不得泄漏。
- 验证个人中心的资料修改、密码修改、账号生成记录、算力明细和任务中心；生成记录按账号和企业隔离，跨设备删除不复活，失败记录、结果预览和下载正常。
- 验证管理后台运营看板、用户、生成任务、算力日志、兑换码、公告、签到、提示词、素材、模型中心、渠道和系统设置；指标应随真实业务变化，批量删除只影响目标记录。

### 画布编辑与生成交互

- 验证移动端画布触控：单指拖动画布、两指以手势中心平滑缩放且连续移动不发生指数跳变，缩放范围保持 5%–500%；节点长按 550ms 打开中文操作菜单，移动超过 8px 或第二根手指加入时取消长按，长按菜单可加入/移出多选并对多个节点执行底部删除。窄屏底部工具栏应全宽横向滚动且不被缩放控件遮挡，助手面板应占满手机宽度、隐藏拖宽手柄，并可完成选中节点引用、提示词输入和图片生成；横竖屏切换、系统返回、面板收起、触控取消及桌面鼠标右键/滚轮/框选行为不能回归。
- 验证生成配置节点的提示词浮层、`@` 资源候选、图片/视频/音频/文本编号、高亮、键盘滚动和上游引用解析；预览、拖动、设置控件及连线吸附互不干扰。
- 验证图片节点局部编辑、复制提示词、放大、超分、切分、自定义快捷工具栏；新结果位置、自动连线、撤销、刷新恢复和提示词来源正确。
- 验证文本节点双击编辑、拖选文字、只读/编辑排版和引用高亮；节点底部图片、视频、音频参数浮层不会触发画布跳转、拖拽、取消选中或意外关闭。
- 验证画布手动保存、自动保存、`Ctrl/Cmd + S`、生成期间云端同步和停止生成；长任务不会被同步误判为中断，取消后保留已完成结果并清理未完成 loading 节点。
- 验证画布项目与素材 ZIP 导入导出，包内 JSON、图片、视频映射完整；多项目批量导出可恢复，删除节点或清空画布后撤销不会丢失媒体。

### 创作台、记录与参数面板

- 验证生图工作台参考图排序、紧凑参数面板、16 倍数对齐、1K/2K/4K、宽高比、质量、张数和历史配置回填；空缩略图不应渲染无效图片。
- 验证视频创作台的参考素材、模型、比例、清晰度、时长、声音、水印、生成记录和错误展示；`auto` 参数不发送，数值输入在提交时按协议归一化。
- 验证配置与用户偏好弹窗可选择图片、视频、文本和音频默认模型及画布默认生图张数；账号偏好 800ms 防抖保存、跨设备恢复、账号隔离和断网行为正确。

### 模型与渠道管理

- 验证渠道新增、编辑、模型拉取、手工补充、API Key 留空沿用旧值和模型测试；公开可用模型由已启用渠道合并，失效默认模型自动修复。
- 验证逐模型的对外名称、上游名称、支持操作、比例、时长、分辨率和权重选路；两个同名渠道能力不同时，请求必须进入满足操作和规格要求的渠道。
- 验证后台素材文件上传及 `/api/asset-files/{name}` 访问，图片、视频、音频可在前台素材库查看、复制和加入“我的素材”。

## P2 · 一般回归

### 界面与品牌一致性

- 确认“道生画境”名称、Logo、favicon、浏览器标题、登录页、后台、画布库、导出文件名、README 和文档站一致。
- 验证浅色、深色和移动端首页布局；Tooltip、顶部状态栏、登录入口、算力余额、购买算力、公告、签到和账号菜单的颜色、显隐及刷新行为正常。
- 验证管理后台系统设置的分类 Tabs、模型渠道独立页面和中文文案，不再出现乱码；用户端不展示渠道名称、Base URL、API Key 或内部渠道说明。
- 验证画布连线右键删除、连接吸附、节点参数浮层层级、工具栏更多菜单以及文档入口等低风险交互。

### 文档站与发布信息

- 验证文档站中文搜索、`/api/search`、LLM 文本路由和 Next.js standalone Docker 镜像；主应用在登录和未登录状态下均可从配置地址打开文档站。
- 验证版本更新弹窗读取当前仓库 `yypyyd/infinite-canvas` 的 `CHANGELOG.md`，未发布内容、历史版本和日期展示正确。

## 验收顺序

1. 先在 PostgreSQL 或 MySQL 环境完成全部 P0，并记录失败场景和修复提交。
2. P0 通过后执行 P1 主流程回归，优先覆盖 Chrome 桌面端和真实上游账号。
3. 最后集中验证 P2；发布前重新跑一遍登录、企业切换、生成、保存、扣费和批量 Worker 冒烟测试。
