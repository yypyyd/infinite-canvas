# API 对接指南

接口地址是 `https://huantu.xyz/api/v1`。鉴权只传 `Authorization: Bearer ic_live_...`，不要传企业编号。官方 SDK 的 `base_url` 用同一个地址。失败看 HTTP 状态码和 `error.message`。

带真实模型 ID 的请求在站内[模型广场](/api-docs)复制。这里只说明类型差别：

- [图片](/docs/api/image)：同步返回图片
- [视频](/docs/api/video)：创建、查询、下载
- [音频](/docs/api/audio)：成功时响应体就是文件

站内页是[对接目录](/api-docs/integration)。
