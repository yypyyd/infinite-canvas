# API 对接指南

先选类型。图片、视频、音频接口和返回体都不一样，不要混着看。站内页：

- [对接目录](/api-docs/integration)
- [图片对接](/api-docs/integration/image)
- [视频对接](/api-docs/integration/video)
- [音频对接](/api-docs/integration/audio)

模型 ID 以 `GET /models` 为准。鉴权只传 `Authorization: Bearer ic_live_...`，不要传企业编号。

## 图片

图片是同步接口。一次请求结束就返回图片，没有任务号。完整步骤看[图片对接](/docs/api/image)。

## 视频

视频是异步任务：创建 → 用 `id` 查询 → `completed` 后再下载。完整步骤看[视频对接](/docs/api/video)。

## 音频

音频成功时响应体就是文件。完整步骤看[音频对接](/docs/api/audio)。
