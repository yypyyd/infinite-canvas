- 验证个人中心的资料修改、密码修改、账号生成记录、算力明细和任务中心；生成记录按账号和企业隔离，跨设备删除不复活，失败记录、结果预览和下载正常。

### 画布编辑与生成交互

- 修复画布原生滚轮拦截误伤交互面板的问题：节点提示词与组装提示词面板出现滚动条后，鼠标滚轮应滚动面板内容且不改变画布缩放；鼠标移回画布空白区域后仍正常缩放。需要回归提示词输入、弹窗、下拉菜单以及明暗主题。
- 修复空白双击创建节点菜单在移动画布工具下只能点击关闭按钮的问题：菜单打开后单击任意画布空白区域应立即关闭，拖动画布仍保持平移，点击菜单内部和节点不应误关闭。需要分别在移动、选择工具以及不同画布缩放比例下验证。
- 验证画布视频解析与一键爆款：包含内容的视频节点悬浮工具条应显示“解析”和“爆款”，点击后直接以当前节点为来源，右侧面板只显示与入口一致的单个执行按钮；视频解析应抽取 6 个时间均匀分布的关键帧，并使用当前文本模型生成包含钩子、叙事、镜头、字幕、情绪与转化策略的中文报告；一键爆款应在此基础上创建原创改编脚本、首帧参考图、视频生成配置及连线，以紧凑网格排列并自动缩放居中展示完整链路，可选择仅编排或立即生成成片。模型未返回完整爆款结构时应明确失败，不得把原始回答同时当作脚本和视频提示词。需要验证空节点不显示入口、短视频、横竖屏视频、私有云端视频、模型未配置、解析失败、关闭面板和生成中断场景；产物刷新后应从服务端恢复，且不得照搬原品牌、人物或具体台词。
- 验证画布长时间运行性能优化：连续生成、上传、删除大量图片、视频和音频后，浏览器内存不应因模块级 Blob/Object URL 缓存持续增长；媒体尺寸与时长读取结束后应立即释放临时资源，服务端文件仍可正常预览、下载、导入和导出。创建大量节点与连线后持续平移、缩放和拖拽单个或批量节点，未变化节点与连线不应逐帧重复渲染，节点引用编号、连线跟随、小地图、撤销重做、自动保存和刷新恢复保持正确。
- 验证移动端画布触控：单指拖动画布、两指以手势中心平滑缩放且连续移动不发生指数跳变，缩放范围保持 5%–500%；节点长按 550ms 打开中文操作菜单，移动超过 8px 或第二根手指加入时取消长按，长按菜单可加入/移出多选并对多个节点执行底部删除。窄屏底部工具栏应全宽横向滚动且不被缩放控件遮挡，助手面板应占满手机宽度、隐藏拖宽手柄，并可完成选中节点引用、提示词输入和图片生成；横竖屏切换、系统返回、面板收起、触控取消及桌面鼠标右键/滚轮/框选行为不能回归。
- 验证生成配置节点的提示词浮层、`@` 资源候选、图片/视频/音频/文本编号、高亮、键盘滚动和上游引用解析；预览、拖动、设置控件及连线吸附互不干扰。
- 验证图片节点局部编辑、复制提示词、放大、超分、切分、自定义快捷工具栏；新结果位置、自动连线、撤销、刷新恢复和提示词来源正确。
- 验证画布第一优先级交互：节点提示词可展开为大编辑器，紧凑面板和大编辑器输入 `@` 都能列出当前画布中尚未连线的真实图片、视频及其他可用资源，选择后自动建立输入连线并实际进入生成请求；画布没有可引用媒体时应显示明确空状态，不再毫无反应。`@` 搜索、键盘选择、长文本滚动和草稿恢复正常；打开大编辑器时底层紧凑面板的 `@` 候选菜单应同步关闭，不得从弹窗底部漏出；选择图片等资源后，引用应在提示词框内部只显示无圆角矩形缩略图、不显示资源文字，双击图片应打开大图预览，缩略图存在时输入光标仍清晰可见，Backspace/Delete 在光标贴近缩略图时应一次删除整个资源引用，删除引用文字后对应缩略图同步消失；节点下方提示词/组装面板和创建节点菜单在画布 5%–500% 缩放时保持屏幕像素尺寸，提示词面板以节点中心为锚点，创建菜单从点击位置展开；提示词面板使用基础尺寸的 1.5 倍，仅位置跟随节点；底部工具栏的选择/移动工具、Ctrl/Cmd 或 Space 临时切换、空白画布框选与双击创建节点正常；图片切分弹窗的横竖分割线可拖拽、添加、删除和重置，生成子节点数量、顺序、尺寸与自定义网格一致。
- 验证画布多图批次交互：新生成的批次按最多四列排列，已有画布和已手动移动的子图位置不被自动重排；切换主图时根节点的屏幕尺寸和位置保持不变，同时更新内容、存储键、原始尺寸、类型与字节信息；根节点和每个展开子图的工具栏均可直接下载对应原文件，双击图片仍只打开预览；开始缩放节点时悬浮工具栏隐藏，缩放批次根节点时已展开子图自动收起，鼠标松开、窗口失焦或组件卸载后缩放状态均能恢复。
- 验证文本节点双击编辑、拖选文字、只读/编辑排版和引用高亮；节点底部图片、视频、音频参数浮层不会触发画布跳转、拖拽、取消选中或意外关闭。
- 验证画布手动保存、自动保存、`Ctrl/Cmd + S`、生成期间云端同步和停止生成；长任务不会被同步误判为中断，取消后保留已完成结果并清理未完成 loading 节点。
- 验证画布项目与素材 ZIP 导入导出，包内 JSON、图片、视频映射完整；多项目批量导出可恢复，删除节点或清空画布后撤销不会丢失媒体。

### 模型与渠道管理

- 验证配置驱动的 AutoDL ComfyUI 渠道：后台可在统一渠道页选择 `AutoDL ComfyUI`，Token 留空沿用旧值，每个图片/视频模型分别保存工作流 ID、JSON 请求模板和参数映射；AutoDL 不请求模型列表，配置测试不提交付费任务。分别用文生图、带工作区参考图的图生图、文生视频和带参考素材的视频工作流验证占位符、枚举映射、渠道能力选路、预扣费和幂等请求号。创建成功后图片在当前连接或断线恢复 Worker 中完成，视频由现有轮询和后台 Worker 完成；临时结果 URL 不进入浏览器、任务结果或日志，HTTPS 公网/重定向/MIME/80MiB 上限校验有效，成功作品立即归档到当前配置的七牛或本地存储，失败、无结果及 30 分钟超时按原个人/企业扣费来源只退款一次。还需在真实 AutoDL 账号确认 `Authorization: <Token>`、创建/查询状态字段和多结果顺序与官方生产接口一致。
- 验证 OpenAI 兼容视频闭环：渠道模型拉取应读取 `/models?extended=true` 的 `kind`、`supported_ratios`、`supported_resolutions`、`supported_durations`、`max_reference_images`、`max_reference_videos`、`max_reference_audios`、`max_reference_media`、`supports_audio_output` 和 `reference_mode`，未返回的单项能力保留管理员手工配置；同步到模型中心和 `/api/v1/models` 后用户端展示最终能力。营销视频页和画布应分别按模型上限接收参考图、视频和音频，并按合计上限过滤，创建请求通过 `input_reference`、`reference_videos`、`reference_audios` 完整转发，开启音频输出时发送 `generate_audio=true`；渠道选路拒绝任一单类超量、合计超量或不支持音频输出的请求。使用 `firefly-seedance-2-fast` 回归 9 图、3 视频、3 音频、合计 9 的边界，并验证单图 20MiB、单视频 200MiB、单音频 50MiB 和整体 320MiB 限制；任务查询与内容下载分别使用 `GET /videos/{id}`、`GET /videos/{id}/content`。
- 验证视频渠道选路与计费：同一对外模型配置多个渠道时，按类型、操作、比例、分辨率、时长筛选；模型中心每个分辨率只维护一个每秒单价，实际费用按请求秒数计算且没有默认规则兜底，预扣、成功结算、失败退款和前端费用预估一致。渠道测试只读取 `/models?extended=true`，不得创建生成任务或产生上游费用。
- 验证渠道新增、编辑、模型拉取、手工补充、API Key 留空沿用旧值和模型测试；公开可用模型由已启用渠道合并，失效默认模型自动修复。
- 验证渠道重新拉取模型并确认选择后，新增和已有模型都应使用本次 `/models?extended=true` 返回的类型、非空比例、分辨率、时长、参考图数量和模式；上游未公布比例或参考图能力时保留当前手工配置，其余已返回能力准确替换旧值。切换渠道或手工打开选择器时不得复用上一次渠道的发现结果，上游模型名与手工操作配置保持不变。
- 验证逐模型的对外名称、上游名称、支持操作、比例、时长、分辨率和权重选路；图片和视频渠道都可手工补充比例，上游未返回比例时不得清空已有手工值；模型中心可直接输入任意模型 ID，并可在计费区域直接输入自定义分辨率档添加价格，同时将新档位同步到模型能力。两个同名渠道能力不同时，请求必须进入满足操作和规格要求的渠道。
- 验证后台素材文件上传及 `/api/asset-files/{name}` 访问，图片、视频、音频可在前台素材库查看、复制和加入“我的素材”。
