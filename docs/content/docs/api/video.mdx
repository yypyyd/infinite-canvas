# 视频对接

视频是异步任务。路径是 `POST /videos`，不是 `/video`，也不是 `/videos/generations`。站内说明在 [/api-docs/integration/video](/api-docs/integration/video)，可复制请求在[模型广场](/api-docs)。

| 步骤 | 接口 | 成功时看什么 |
| --- | --- | --- |
| 创建 | `POST /videos` | 顶层 `id` |
| 查询 | `GET /videos/{id}?model=模型ID` | `status`，必须带创建时的模型 ID |
| 下载 | `GET /videos/{id}/content?model=模型ID` | MP4。`Content-Type` 若是 JSON，就是失败 |

每 2–3 秒查一次，只有 `completed` 才能下载。任务号是 `id`。HTTP 状态码大于等于 400 就停，读 `error.message`。`seconds` 和 `size` 以模型广场里该模型的能力为准。

还没拿到 `id` 时，用原 `Idempotency-Key` 调用 `GET /generation-tasks/recovery`。
