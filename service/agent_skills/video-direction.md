# 短视频与营销视频

## 适用
商品短视频、营销广告片、社媒短片的脚本、分镜和视频生成。

## 先想清楚
- 目的（种草、促销、品牌）、平台与画幅（抖音和小红书竖屏 9:16，电商主图视频 1:1 或 3:4，横屏 16:9）、总时长。
- 单段视频时长受模型限制（常见 5–10 秒）；更长的成片拆成多段，每段只做一个镜头或一个动作。

## 脚本结构（15–30 秒）
1. 钩子（0–3 秒）：最抓眼的画面或一个问题。
2. 展示（3–15 秒）：商品出场，加 1–3 个卖点，每个卖点一个镜头。
3. 场景（可选）：使用场景或效果对比。
4. 收尾（最后 2–3 秒）：商品定格，加行动号召（文字后期叠加）。

## 分镜表
每个镜头写清：镜号、时长、景别（特写、近景、中景、全景）、运镜（推、拉、摇、跟、环绕、固定）、画面内容、字幕或口播（如有）。分镜先在侧栏给出，用户要求时再放到画布（文本节点按镜号从左到右排列）。

## 视频提示词
- 结构：主体 + 一个清晰的动作 + 场景 + 镜头运动 + 光线 + 风格 + 节奏。例如："一只磨砂黑保温杯放在晨光中的木质桌面上，热气缓缓升起，镜头从杯身特写慢慢拉远到桌面全景，暖色自然光，产品广告质感，节奏舒缓"。
- 一段视频只做一个动作或一次运镜，不要在几秒里塞多个场景切换。
- 不要让模型生成文字和字幕。

## 一致性做法
- 商品或角色需要保持一致时，先生成（或使用已有的）关键帧图片，再图生视频（video_generate 的 imageNodeIds 传首帧）。
- 多段视频共用同一张商品参考图和同一套光线、色调描述；需要衔接时，用上一段的结尾画面作为下一段的首帧参考。

## 检查点
- 多段视频（2 段及以上）开始生成前：谨慎或标准模式先把分镜表发给用户，并用 agent_ask_user 确认方向（2–3 个创意方向，或"按此分镜继续 / 先调整分镜"），推荐项放第一；自主模式直接按分镜执行并说明假设。
- 关键帧图片全部生成并验收后、生成依赖它们的视频之前：谨慎模式用 agent_ask_user 让用户确认关键帧（"满意并继续"放第一，"先暂停"第二）；标准和自主模式不暂停。
