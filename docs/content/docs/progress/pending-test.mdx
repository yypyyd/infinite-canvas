# 待测试

- 独立视频生成页的“开始生成”按钮会按当前模型、分辨率、时长和用户组倍率显示预计算力消耗，并在切换参数后同步更新。需要验证 480P、720P、1080P 和不同秒数的按钮报价与实际扣费一致，未配置对应价格时不显示错误报价。
- 修复 480P 视频因偶数像素取整导致渠道比例匹配失败的问题：`854×480` 和 `480×854` 会分别归一化为 `16:9` 与 `9:16`，不再被识别成 `427:240` 或 `240:427`。需要验证 `firefly-seedance-2-fast` 在 480P 横屏、竖屏和 4–15 秒配置下均可进入已配置渠道，并回归 720P、1080P 及其他比例不受影响。
- 管理后台渠道模型和模型中心的“支持时长”预设已覆盖 4–30 秒的全部整数秒。需要验证两个入口均可直接选择范围内任意时长，保存后模型能力、用户端视频时长和渠道路由同步生效。
- 图片生成和参考图编辑在上游明确建连失败或返回 500/502/503 时，会保留原任务与单次预扣，排除已失败渠道并改选其他满足同模型、操作、分辨率和参考图能力的渠道；408/504/520–525 会先用幂等编号查询原渠道任务，只有原渠道明确不支持任务查询才切换，连接重置等提交结果不确定的错误不会跨供应商重发；内容策略拒绝不换渠道，全部兼容渠道失败后才记失败并退款。生成任务的渠道更新、成功完成和失败退款遇到 SQLite 锁竞争时会短暂退避重试。需要验证 1K 在 `krill` 返回临时错误时可切换到 `myVividAI`，4K 无第二兼容渠道时保留原错误，内容策略拒绝不重试；同时以 10 个图片请求并发回归仅扣费一次、成功不退款、最终失败只退款一次，任务不残留“运行中”。
- 修复 VividAI 图片规格判与渠道选路不一致、参考图类型在 multipart 适配时丢失的问题：通用的“高质量”不再被误当成 4K，图片请求会在选渠道、计费和创建任务日志前统一根据像素尺寸归一化分辨率档，转发参考图时保留原始 MIME 类型。需要验证 1K 高质量请求仍可进入只支持 1K 的渠道且不会被改写为 4K，2K/4K 请求只进入声明对应能力的渠道，预计算力、实际扣费和生成任务的分辨率一致；同时使用 PNG、JPEG 和 WebP 参考图回归 JSON 与 multipart 请求，不再出现 `unsupported reference image type`。
- 管理后台用户管理新增可复制的用户 ID 列，算力点日志按用户名和可复制用户 ID 组合展示；两处关键词搜索同步支持用户 ID，算力点日志额外支持用户名。需要验证长用户名和长用户 ID 的省略、复制、关键词筛选、分页，以及用户已删除时日志仍保留用户 ID 并显示“未知用户”。
- 修复商品图生成时工作区保存返回“操作失败”的问题：工作区保存时间改为按企业显式更新、不存在时创建，不再依赖 SQLite 旧表中缺失的 `organization_id` 唯一约束；强制同步连续失败后会显示服务端返回的真实错误，离线和通用未保存文案不再误导为企业切换；AI 请求尚未开始时，待生成结果和左侧记录会立即收敛为失败状态。需要使用现有 SQLite 数据库验证 `/api/workspace/changes` 正常保存，首次生成、重新生成和后台自动同步不再出现 `ON CONFLICT` 错误；同时验证接口断开、无企业生成权限、版本冲突及正常保存场景下提示准确，保存失败不发起 AI 请求、不扣费且页面不残留无限加载状态，并回归全新 SQLite、MySQL 和 PostgreSQL 数据库。
- 商品图、营销视频、画布和画布助手的生成记录改为任务开始时立即创建“生成中”记录，并在结果返回后更新原记录，不再等全部生成完成才新增；商品图批量生成会逐张更新 `已完成/总数`、成功缩略图与失败数，最终显示成功、部分失败或失败，个人中心同步展示相同状态；营销视频刷新后仍可点击“生成中”记录恢复提示词、参考素材、参数和等待状态，同页生成完成时已打开的记录会同步到最终状态。需要验证发起生成后左侧或个人中心立即出现且只出现一条记录，商品图 3–10 张乱序完成时计数和缩略图持续更新且不重复建记录，单张失败、部分失败、全部失败、取消及页面中途刷新后的状态与服务端持久化符合预期；同时验证视频、画布节点重试、画布局部编辑、画布助手普通生图和 Agent 图片/视频工具的记录均由“生成中”正确收敛到最终状态。
- 修复商品图生成完成后左侧记录可能不新增的问题：媒体上传凭证的申请、确认和取消改为统一串行写入，SQLite 默认增加 5 秒写锁等待；商品图和画布助手的批量结果改为逐项收集保存结果，单张上传失败不会再阻断整批记录，营销视频和画布批量生图也复用同一上传保护。需要验证商品图连续生成 1 张和 3–10 张时左侧记录立即新增且刷新后仍存在，商品图及画布助手部分上传失败时保留成功图片并明确提示；同时验证营销视频、画布单图/多图/视频和画布助手生成后，工作台或个人中心生成记录、跨设备预览和删除均正常。

- 按仓库锁定的 Prettier 3.8.3 和现有配置统一格式化 Web 源码，未修改格式规则或业务逻辑。需要在 CI 验证 `format:check` 通过后继续执行 `types:check`。

本文档只记录已经实现、尚未完成验收的能力。测试按风险分为三个优先级：

- **P0 发布阻断**：涉及数据安全、租户隔离、计费、持久化或核心生成链路；未通过时不建议发布。
- **P1 核心体验**：影响主要业务流程和高频操作；应在当前版本发布前尽量完成。
- **P2 一般回归**：界面细节、文档、品牌一致性和低风险交互；可在 P0、P1 稳定后集中验证。

完成测试后直接删除对应条目；发现问题时回到代码修复，不把未实现功能写入本文档。

## P0 · 发布阻断
