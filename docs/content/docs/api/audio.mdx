# 音频对接

音频是同步接口。成功时响应体就是文件，不是 JSON，也没有任务号。站内说明在 [/api-docs/integration/audio](/api-docs/integration/audio)，可复制请求在[模型广场](/api-docs)。

接口是 `POST /audio/speech`。HTTP 状态码大于等于 400，或 `Content-Type` 变成 `application/json`，就读 `error.message`。超时用原 `Idempotency-Key` 调用 `GET /generation-tasks/recovery`。
