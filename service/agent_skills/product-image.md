# 电商商品图

## 适用
商品主图、白底图、场景图、卖点图、细节图、模特上身图，以及整套商品图。

## 先确认的事实
- 商品是什么、核心卖点（最多 3 个）、目标平台和人群。画布上有商品图时把它当作外观参考（image_generate 传 referenceNodeIds，或用 image_edit 在原图上修改）。
- 用户没给卖点时，从商品外观能看出的特征出发（材质、结构、用途），不要编造功能和参数。

## 图类型与做法
- 主图：1:1，主体居中、占画面 60%–80%，背景干净（纯色或浅渐变），光线均匀，商品完整不裁切；突出质感和第一眼辨识度。
- 白底图：纯白背景，无投影或极淡投影，主体完整、边缘清晰。已有商品图时优先用 image_edit 换成白底。
- 场景图：把商品放进真实使用场景，场景元素服务于卖点（保温杯 → 清晨办公桌与升起的热气），商品仍是视觉焦点，背景适度虚化。
- 卖点图：一张图只讲一个卖点，用构图和道具表达（防水 → 水珠飞溅），说明文字放画布文本节点。
- 细节图：微距特写材质、做工、接口，用侧光强调纹理。
- 模特上身图：写清模特性别、年龄段、姿势和穿搭，保证商品在画面中完整、清晰。

## 整套商品图
1. 先规划结构：主图 1 张 + 场景图、卖点图或细节图 3–5 张，统一色调、光线和背景风格。
2. 用 canvas_plan 列出每张图的目标，分批生成（单次最多 4 张）。
3. 每次生成都带上同一张商品参考图，提示词里重复关键外观特征，保证是同一件商品。
4. 生成后按自检清单核对；风格不统一的图优先用 image_edit 修正，而不是整套重来。

## 尺寸建议
主图和白底图 1:1（如 2048x2048）；详情页模块 3:4 或 2:3；横版 banner 16:9。用户或配置节点已指定尺寸时以指定为准。

## 检查点
- 整套商品图（3 张及以上）且用户没有给出任何风格或场景方向时：自主等级为谨慎或标准，生成前调用一次 agent_ask_user，给 2–3 个完整的视觉方向（例如"极简棚拍""生活场景""暗调质感"），推荐项放第一；自主等级为自主时直接按推荐方向执行，并在交付时说明这个假设。
- 单张图，或用户已经给出方向时，不要提问。
