# 创作通用规范

## 作用
所有专业创作共用的事实边界、范围控制、提示词写法和交付自检。领域 Skill 在此基础上补充方法。

## 事实边界
- 只使用用户给出的信息、画布上已有的素材和工具返回的真实结果。品牌名、卖点、参数、价格、认证、销量和用户评价不得编造；用户没给时用中性描述或留出占位，并在交付时说明。
- 参考图里能看到的商品外观（颜色、材质、结构、logo 位置）是硬约束，提示词里要明确保持，不要擅自改款。
- 文字、标志、二维码和水印默认不出现在生成画面里；需要文字时优先放到画布文本节点，或明确告诉用户图中文字可能不准确。

## 范围控制
- 用户要几张就生成几张，要多长就做多长；没说数量时默认最小可交付量（图片 1 张、视频 1 段），不要靠多生成来"试方向"。
- 一次只解决当前目标；顺手的扩展（多做几个版本、额外配文案）用一句话建议，不要直接执行。

## 提示词写法
- 用完整的描述性句子，按"主体 → 外观细节 → 场景与道具 → 构图与景别 → 光线 → 风格与质感 → 画面约束"的顺序组织。
- 主体放在最前面，用具体名词和可见特征描述（"磨砂黑色保温杯，杯身有一圈银色细环"），不要只写抽象形容词（"高级""好看"）。
- 构图写清景别和视角（特写、中景、俯拍 45 度、平视），以及主体在画面中的位置和占比。
- 光线写清方向和质感（左上方柔光箱、逆光轮廓光、窗边自然光）。
- 风格用能画出来的词（棚拍产品摄影、极简扁平插画、胶片质感），不要堆砌互相冲突的风格。
- 约束放在最后：不要文字和水印、不要变形、保持商品外观与参考图一致。
- 一条提示词只描述一个画面；多张不同画面分别写。

## 交付自检
交付前逐项核对：数量和规格是否与要求一致；商品或角色是否与参考保持一致；是否出现了不该有的文字、水印或明显畸形；多张图或多段视频之间的风格、光线、色调是否统一；用户的每一项要求是否都已完成，没完成的是否说明了原因。
