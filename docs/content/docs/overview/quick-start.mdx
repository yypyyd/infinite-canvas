# 快速开始

如果你只是想先把项目跑起来，优先使用 Docker。

## Docker 启动

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cp .env.example .env
docker compose up -d
```

启动后访问：

```text
http://localhost:3000
```

默认管理员账号：

```text
用户名：admin
密码：.env 中的 ADMIN_PASSWORD
```

## 本地构建镜像启动

如果你需要基于当前源码本地构建镜像：

```bash
cp .env.example .env
docker compose -f docker-compose.local.yml up -d --build
```

## 首次使用建议

- 先进入管理后台配置上游渠道、模型中心和计费规则。
- 注册或登录用户账号后，再进入画布、我的素材、生图或视频创作台。
- 如果需要提示词仓库内容，可进入 `/admin/prompts` 拉取或同步。

## 说明

- 登录账号的画布、“我的素材”、生成记录、媒体和偏好只保存在服务端，必须联网使用，浏览器不保存离线账号缓存。
- 用户端只请求同源 `/api/v1/*`，上游 Base URL 和 API Key 只保存在管理后台私有配置中。
