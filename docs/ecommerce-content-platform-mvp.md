# 企业级电商内容平台 P0 产品规划

> 项目：`infinite-canvas`  
> 范围：第一阶段 MVP，仅规划，不涉及代码改造

## A. 可复用能力与关键缺口

### 可直接复用

- **企业底座**：企业多租户、成员邀请与切换，`owner/admin/member/reviewer` 角色，企业审计与数据隔离。
- **商品与品牌**：品牌规范、SPU/SKU、卖点、属性、目标人群、SKU 参考图。
- **AI 生产**：图片生成/编辑、文本生成、多模型渠道、视频创建与轮询、按模型计费及失败退款。
- **批量生产**：生产模板版本、商品/SKU 输入快照、批量任务、Worker 租约、幂等、取消、失败重试和私有归档。
- **审核交付**：结果通过/驳回、批注、重生成、主图选择、结果对比、保存素材、创建画布、ZIP 导出。
- **内容资产**：无限画布、企业素材、生成记录、私有图片/视频/音频存储及服务端持久化。

### P0 关键缺口

1. 上述企业、电商与批量能力大量处于“已实现待验收”，租户隔离、权限、计费、Worker、对象存储、备份恢复必须先完成真实环境验收。
2. 当前企业、品牌、商品、模板、任务与审核集中在单个企业中心页面，缺少清晰的生产型信息架构。
3. 图片批量链路较完整，但商品视频尚未进入统一的服务端任务、归档、审核和交付闭环。
4. 缺少面向业务人员的商品批量导入、字段映射、错误行回执和资料完整度检查。
5. 导出以图片任务 ZIP 为主，缺少“商品级图片+视频+manifest”的统一交付包。

## B. 产品定位与目标用户

### 产品定位

**面向电商品牌与代运营团队的企业级 AI 商品视觉生产平台。** 以品牌规范、商品/SKU 和参考素材为输入，批量生产可审核、可追踪、可按平台规范导出的商品图与商品视频。

核心价值：

- 将分散的商品资料、素材、AI 生成、团队审核和交付统一成一条生产线。
- 通过商品一致性、品牌规范、模板版本和人工审核降低 AI 内容不可控风险。
- 用批量任务与平台规格减少重复操作，缩短多 SKU 内容交付周期。

### P0 目标用户

- **电商品牌内容/运营团队**：SKU 多、上新频繁，需要稳定产出主图、场景图和短视频。
- **代运营与设计服务团队**：管理多个客户品牌，需要权限隔离、批量交付和审核留痕。
- **审核负责人/品牌负责人**：关注商品一致性、品牌合规、交付规格和成本。

## C. P0 MVP 业务闭环

1. **商品导入**：创建品牌；通过表格导入或表单录入 SPU/SKU、卖点、属性、目标人群和参考图。系统校验编码重复、必填字段、图片数量与格式，并返回错误行。
2. **素材管理**：参考图上传至企业私有素材库，绑定品牌/SPU/SKU；支持搜索、预览、替换、删除和引用状态查看，跨企业不可访问。
3. **AI 商品图**：选择商品/SKU、生产模板、参考图和目标规格，预览输入与预计用量后创建任务；至少支持白底主图、场景图。任务支持排队、执行、取消、失败重试和刷新恢复。
4. **AI 商品视频**：基于商品资料、图片结果和视频模板生成 6–15 秒商品视频；服务端负责异步轮询、停止、失败退款、结果归档与恢复。P0 每个 SKU 至少支持一种横版或竖版规格。
5. **审核**：按商品聚合图片和视频；审核人可通过、驳回并填写批注，成员按批注重生成；仅通过的结果可设为主图/主视频和进入导出。
6. **导出**：按商品/SKU 建目录，输出已通过的图片、视频和 `manifest.json`；记录导出人、时间、任务、模板版本和产物清单。

### P0 成功标准

- 20 个商品、100 个 SKU 可连续完成生产、审核和导出，任务不重复生成或扣费。
- 企业间商品、素材、任务和结果零串租户；角色越权请求全部阻断并留审计记录。
- 审核通过的产物 100% 满足所选尺寸、格式、命名和目录规则。
- 图片/视频任务异常后可恢复或重试，失败只退款一次。

## D. P0 页面清单

1. **工作台**：待处理任务、待审核数、近期产出、用量与快捷创建。
2. **商品中心**：品牌、SPU/SKU 列表，批量导入、资料完整度、参考素材关联。
3. **素材库**：企业图片/视频素材，按品牌、商品、类型筛选。
4. **图片工厂**：选择商品、模板、规格，创建批量商品图任务并查看进度。
5. **视频工厂**：选择商品、图片输入、视频模板和规格，创建视频任务并查看进度。
6. **任务中心**：统一呈现图片/视频任务的状态、消耗、失败原因、取消与重试。
7. **审核中心**：按商品聚合结果，对比、通过、驳回、批注、设主图/主视频。
8. **交付中心**：筛选审核通过内容，预检并生成、下载交付包。
9. **企业管理**：企业信息、成员邀请/角色、共享用量设置、审计日志。

## E. 企业成员角色权限

| 能力 | 所有者 Owner | 管理员 Admin | 成员 Member | 审核人 Reviewer |
|---|---|---|---|---|
| 企业设置、所有权转移 | 全部 | 查看 | 查看 | 查看 |
| 邀请、改角色、移除成员 | 全部 | 除所有者外 | 无 | 无 |
| 品牌、商品、素材、模板维护 | 全部 | 全部 | 新增/编辑/使用 | 只读 |
| 创建、取消、重试生产任务 | 全部 | 全部 | 全部 | 只读 |
| 审核、驳回、设主结果 | 全部 | 全部 | 无 | 全部 |
| 导出审核通过结果 | 全部 | 全部 | 允许 | 允许 |
| 用量与预算配置、审计日志 | 全部 | 全部 | 仅看自身/摘要 | 仅看摘要 |

原则：所有业务请求必须携带并校验企业上下文；敏感写入采用乐观版本控制；角色变更、审核、用量和导出必须留审计记录。
