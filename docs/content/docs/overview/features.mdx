# 功能介绍

本文档记录当前项目已经完成验收的主要功能。近期实现但尚未完成验收的企业多租户、品牌与商品中心、批量生产、企业私有媒体和模型能力调整，请查看[待测试清单](/docs/progress/pending-test)；通过验收后再并入本文档。

## 画布项目

- 支持创建多个画布项目。
- 支持项目重命名、删除、批量选择和批量删除。
- 支持单个画布项目导出为 JSON，也支持从 JSON 导入画布。
- 画布项目只保存在登录账号的服务端，浏览器刷新时重新读取，不提供离线保存。

## 画布工作台

- 支持拖动画布、滚轮缩放、缩放滑杆和重置视图。
- 支持小地图定位，可开关小地图。
- 支持点阵、网格线、空白三种背景。
- 支持浅色和深色主题。
- 支持框选、多选、全选、取消选择、删除选中。
- 支持复制粘贴节点和节点之间的连线。
- 支持撤销和重做节点、连线、视口、背景和助手会话变化。
- 支持节点连线，并高亮当前节点相关的上下游节点和连线。
- 支持快捷键帮助，覆盖缩放、框选、全选、复制粘贴、撤销重做、删除、退出选择和拖入图片。

## 节点

已完成验收的主要节点包括：

- 图片节点：展示上传图片、生成图片或素材库图片。
- 文本节点：保存提示词、说明文案、AI 文字回答等文本内容。
- 生成配置节点：汇总上游文本和图片，统一配置模型、比例、数量后批量生成图片或文本。

节点支持：

- 拖拽移动。
- 四角缩放。
- 图片节点等比缩放或自由比例切换。
- 查看节点基础信息和 JSON。
- 删除、复制、粘贴。
- 通过左右连接点建立上下游关系。

## 图片工作流

- 支持上传图片到新节点。
- 支持拖拽图片文件到画布。
- 支持替换已有图片节点内容。
- 支持下载图片节点。
- 支持把图片节点保存到“我的素材”。
- 支持图片裁剪，并把裁剪结果生成为新的图片节点。
- 支持本地多角度变换，并把结果生成为新的图片节点。
- 支持生成失败后重试。
- 批量生成多张图片时会先展示为图片组节点，支持叠卡预览、展开查看全部结果并设置主图。

## AI 生成

用户端统一请求本项目同源后端 `/api/v1/*`，后端按模型、操作和分辨率选择管理后台配置的上游渠道。上游 Base URL 和 API Key 只保存在服务端私有配置中。

OpenAI 兼容图像和文本能力继续复用现有接口：

- `/api/v1/images/generations`：文生图。
- `/api/v1/images/edits`：图生图/参考图编辑。
- `/api/v1/chat/completions`：文本问答和带图问答。

视频能力支持两类接口：

- OpenAI 风格视频：`POST /api/v1/videos`、`GET /api/v1/videos/{id}`、`GET /api/v1/videos/{id}/content`。
- Seedance 等特殊上游协议由后端渠道适配，前端仍只请求同源接口。

`POST /api/v1/videos` 对外仍支持 multipart 请求；用户端引用已经上传到工作区的图片、视频和音频时，改用 JSON 提交 `input_reference_storage_keys`、`reference_videos_storage_keys` 和 `reference_audios_storage_keys`。Go 服务端会按当前企业校验 `storageKey`，从七牛私有地址流式下载到临时 multipart 文件后转发上游，浏览器和 Next.js 只处理几 KB 的 JSON，不会把大视频重新放进请求体。旧 multipart 调用仍兼容；单张参考图、单个参考视频、单个参考音频分别限制为 20MiB、200MiB、50MiB，整体引用限制为 320MiB。

可配置项：

- 默认模型。
- 图片质量。
- 图片比例。
- 生成数量。
- 视频模型。
- 视频比例、清晰度、时长、生成声音和水印。

普通图片/文本节点可以直接输入提示词生成结果。生成配置节点可以读取上游节点内容，并按节点自己的配置批量生成多个图片或文本结果。生成配置节点支持预览当前提示词和参考图输入，并调整输入顺序。

视频生成可从文本节点读取 prompt，从图片节点读取参考图，从视频节点读取参考视频，从音频节点读取参考音频。Seedance 2.0 支持最多 9 张参考图、3 个参考视频、3 个参考音频；分辨率支持 `480p`、`720p`、`1080p`（fast 模型不支持 `1080p`），比例支持 `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9`、`adaptive`，时长支持 4-15 秒或智能时长。生成成功后会把视频插入画布为视频节点并使用原生播放器预览。用户工作区中的引用通过 `storageKey` 由服务端读取；只有旧版 `/api/v1/media/references` 调用才需要 `PUBLIC_BASE_URL` 生成上游可访问地址。

## 画布助手与画布 Agent

画布右侧助手面板（画布指挥中心）支持：

- 文本问答、生图、读取当前选中节点作为引用（含上游节点自动纳入）、粘贴图片插入画布、历史会话管理、单条或多条会话删除、重试回答、把助手生成的文本或图片插入画布、折叠和展开面板。
- Agent 上下文包含完整画布快照（节点内容、提示词、来源、位置尺寸和连线）；选中节点显示为可移除的上下文 chip，输入 `@` 可搜索并引用图片、视频、音频、文本和生成配置节点，引用以编辑区内联缩略图展示。
- 空画布创作目标和基于画布的建议只填入输入框，再次发送才执行；首次 Agent 执行会确认其可能生成媒体并消耗算力。
- 确定性“整理画布”位于画布工具栏，优先整理选中节点。

Agent 对话模式由服务端编排，支持：

- 单次运行最多八步连续工具调用，复杂任务先通过计划展示步骤；图片、视频和文本结果自动建立来源连线，运行中发送新消息可打断旧任务。
- 开放工具包括图片生成与验收、视频生成与验收、节点排列、添加文本、删除节点和文本修改；删除与文本覆盖需用户逐次确认，确认决定持久记录。
- 图片或视频生成后会用视觉模型对照目标做真实验收，视频按时间顺序抽取关键帧检查；自主模式验收不通过时按修订提示词重新生成一次，第二次仍不通过则停止。
- 缺少关键信息时通过澄清问答提供 3–4 个编号选项并支持自由输入；风格、构图、数量和时长等采用安全默认值，不强制追问。
- 谨慎、标准、自主三档执行策略随账号偏好在服务端保存，跨设备恢复。
- 受控长期记忆：仅在用户明确要求时保存项目偏好、事实或约束，按企业、账号和画布项目隔离，后续运行自动检索注入，可遗忘、可审计。
- 图片或视频工具执行时立即在画布创建“生成中”占位节点，多图独立槽位并从参考节点连线，镜头自动跟随，结果原位更新不重复追加。
- 运行支持可恢复 SSE、事件游标续接、跨页面主动恢复、工具回执和执行租约，多标签页不会重复规划、生成、扣费或修改画布。
- Agent 画布操作可撤销并同步服务端回滚，普通手动编辑不受影响。

## 提示词库

前台提示词库支持：

- 按标题搜索。
- 按标签筛选。
- 按来源筛选。
- 查看提示词详情。
- 查看封面和结果图。
- 复制提示词。
- 把提示词加入“我的素材”。

后台提示词管理支持：

- 查询提示词。
- 新增、编辑、删除提示词。
- 按分组和标签筛选。
- 查看远程提示词源。
- 同步内置远程提示词源。

当前内置远程源包括多个 GPT Image / GPT-4o / Nano Banana Pro 相关提示词仓库。

## 素材

“我的素材”是账号级云端素材库，支持：

- 新增文本素材和图片素材。
- 编辑素材标题、封面、标签、来源、备注和内容。
- 删除素材。
- 按关键词搜索。
- 按类型筛选。
- 分页浏览。
- 复制文本素材。
- 下载图片素材。
- 从提示词库、画布节点和服务器素材库加入素材。
- 在画布中插入素材。

“素材库”是服务器素材库，支持：

- 按标题搜索。
- 按类型筛选。
- 按标签筛选。
- 查看素材详情。
- 复制文本或图片链接。
- 加入“我的素材”。
- 在画布中插入素材。

后台素材库管理支持：

- 查询素材。
- 新增、编辑、删除素材。
- 按类型和标签筛选。

## 账号和后台

- 登录账号会同步主题、默认模型、常用生成参数和图片节点快捷工具栏，换设备后自动恢复；偏好不包含 API Key、会话、缓存或画布业务数据。
- 支持同源 HttpOnly Cookie 会话。
- `/api/auth/me` 可读取当前用户，未登录时返回访客用户。
- 首次启动时根据环境变量创建管理员，并强制要求至少 12 位管理员密码和至少 32 位、长期固定的 JWT 密钥。
- 管理后台包含用户、生成任务、算力日志、兑换码、系统设置、模型渠道、提示词和服务器素材等管理入口。
- 注册、企业成员邀请、个人中心和运营看板的最新调整仍在验收中，具体范围见[待测试清单](/docs/progress/pending-test)。

## 后端能力

- Gin 提供 API 服务。
- Docker 运行时由 Next.js 提供页面入口，`/api/*` 请求代理到内部 Go 服务。
- GORM 管理数据库连接和自动迁移。
- 支持 SQLite、MySQL、PostgreSQL。
- 数据库保存账号、工作区、素材、生成记录、模型任务、计费和后台配置等业务数据；完整结构见[数据库说明](/docs/backend/backend-database)。
- 业务接口统一返回 `{ code, data, msg }`。

## 当前限制

- 画布、“我的素材”和生成记录要求登录；游客不持久化业务数据。
- 浏览器不持久化账号业务数据或偏好；断网时不能保存，恢复联网或刷新后以服务端数据为准。
- 旧版 `/api/v1/media/references` multipart 引用需要 `PUBLIC_BASE_URL` 才能生成上游可访问地址；用户工作区 `storageKey` 引用由服务端直接读取七牛私有对象，不依赖上游访问站点。
- Seedance 返回远程视频 URL 时，前端会尽量下载为本地 Blob 持久化；如果因 CORS 或网络限制无法下载，会保留远程 URL，后续是否可播放取决于上游 URL 的有效期。
- 画布更适合桌面端使用，移动端触控体验还未系统完善。
