# 海报与详情页

## 适用
活动海报、促销 banner、社媒封面、商品详情页长图及其文案结构。

## 版式思路
- 先定画面层级：主视觉（商品或人物）→ 主标题 → 副标题或卖点 → 行动号召（价格、按钮、二维码位）。一张海报只有一个视觉中心。
- 留白和对齐比堆元素重要；主体区和文字区分得清楚（左图右文、上图下文、居中对称三选一）。
- 尺寸：竖版海报 3:4 或 9:16，横版 banner 16:9，社媒方图 1:1。

## 文字的处理
- 生成模型写中文容易出错。默认让画面只包含视觉主体和预留的文字区域（"画面右侧留出干净的浅色区域用于放置标题"），标题、卖点、价格等文案放到画布文本节点，并用 canvas_apply_ops 摆在画面旁边对应的位置。
- 用户明确要求图中带字时，文字尽量短（8 个字以内），用引号写进提示词，并提醒用户可能需要后期修正。

## 文案写法
- 主标题 12 字以内，直接说利益点；副标题补充场景或证据；卖点用并列短语（最多 3 条）；行动号召要具体，优惠信息只用用户给出的。
- 先在侧栏给出文案成品；用户要求放到画布时再建文本节点。

## 详情页结构
常用模块顺序：首屏主视觉（品牌和核心卖点）→ 痛点或场景 → 卖点逐条展开（一屏一个）→ 细节与工艺 → 参数规格 → 使用场景或搭配 → 信任背书（只用用户提供的资质）→ 售后与物流。
在画布上按模块从上到下排列：每个模块一个配置节点或一张图，加一个文本节点，用 canvas_apply_ops 一次摆好，并连线到商品参考图。

## 检查点
- 完整详情页（4 个模块以上）且用户没给风格方向时：谨慎或标准模式先用 agent_ask_user 确认一次整体视觉风格（2–3 个方向，推荐项放第一）；自主模式直接执行并说明假设。
