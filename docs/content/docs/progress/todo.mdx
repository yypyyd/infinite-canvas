## Phase 3 · 已完成（计费单路径）

- 生成主路径：交互 / 批量条目 / Agent / 协议 → `EstimateGenerationPricing`（或等价 `PricingResolver`）→ `BeginGenerationTask` 扣费 → `FinishGenerationTask` 成功完成或失败返还；禁止旁路 `CreditLog` 扣费。
- 晚到货：`DeliverLateAndRecharge`（`ai_late_recharge`）只补扣已返还任务，`failed → success` 幂等，不对成功任务二次扣费。
- Hold/Settle：批量任务与视频渲染共用 `HoldCredits` / `SettleHeldCredits` / `ReleaseHeldCredits`；视频渲染估费 `EstimateVideoRenderPricing` 写入 `PricingSnapshot`。
- 配置侧门：`pool_pricing` 缺口/草稿、价目与优惠只喂 `PricingResolver`，不写流水。文档见[计费生命周期](/docs/backend/billing-lifecycle)。
