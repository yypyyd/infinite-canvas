# Apple Store 式电商 UI 改造概览

## 已完成

- 确立“高级、可信、克制”的 Apple Store 式电商视觉方向。
- 重构全局浅色/深色主题 token：柔和冷灰背景、系统蓝主行动、更大圆角和克制阴影。
- 重做用户端首页：商品陈列式首屏、电商任务入口、短流程说明和灵感画廊。
- 统一顶部导航、商品图与营销视频创作、提示词库、公共/个人商品素材、商品画布项目库、企业中心、个人工作台和登录页的标题层级、容器、卡片和行动样式。
- 登录页改为品牌叙事与账号表单双栏布局，移动端自动退化为聚焦表单的单栏体验。
- 画布编辑详情保留现有低视觉重量工具栏和 `canvasThemes`，避免外围视觉改造影响核心编辑交互。
- 新增 `.impeccable.md` 固化项目设计上下文。
- 在 `pending-test.mdx` 增加本轮视觉、响应式、键盘焦点和深色主题回归项。

## 关键决策

- 商品与结果图承担视觉重心，控件退居次要层级。
- 每个页面突出一个主行动，避免传统后台式按钮竞争。
- 用背景层级、留白与圆角分区替代密集边框和网格装饰。
- 浅色主题优先，同时保留完整深色主题支持。

## 后续建议

- 人工检查所有用户端页面在手机/桌面、浅色/深色主题下的实际效果。
- 重点验收登录页双栏切换、创作页滚动、素材筛选、画布项目操作和账号页 Tabs。
- 按项目约定，本次未执行构建、类型检查或测试。
