- 在已实现的画布素材包编排入口基础上新增服务端素材包任务，以商品 / SKU、品牌规范和目标平台为统一输入，并按平台固化尺寸、比例、文件格式、命名和交付目录；继续补充多商品批量创建、输入快照、预计算力、幂等提交、暂停、重试和进度汇总。
- 首批产物包含商品主图、场景图、详情页图、标题、核心卖点、详情文案和短视频脚本；复用现有图片 Worker、企业生产模板、素材库和画布，补充文本产物的模型调用、版本记录、审核、复制与 JSON / Markdown 导出。
- 第二批补充短视频与封面，复用现有视频模型能力并把异步创建、轮询、归档、失败退款和断点恢复下沉到 Worker；默认生成 6–15 秒平台适配视频，并允许按平台覆盖比例、清晰度、时长、声音和水印参数。

- 平台直发在素材包稳定后单独接入：先完成平台账号授权、店铺与类目映射、字段校验、发布预检、草稿提交、结果回执和审计日志；首版交付包不直接调用第三方发布接口。
